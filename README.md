SCANN 是一个独立的天文瞬变源搜索团队，研究超新星、激变变星及其它瞬变候选体。

目前已发现三颗完成光谱分类的超新星，以及若干激变变星系统。

## 项目简介

候选体先经自动筛选，再由团队成员人工核验；观测时间允许时会开展测光或光谱后随观测。确认的天体提交到公开数据库，包括 TNS（Transient Name Server）与 AAVSO VSX（国际变星索引）。
